# DNS for AI Discovery (DNS-AID) Setup Guide

To enable DNS-based agent discovery, FirstStep uses DNS for AI Discovery (DNS-AID) records under the `_agents` namespace. This guide outlines how to configure these records in your DNS registrar/provider (e.g. Cloudflare, AWS Route 53, Hostinger).

## 1. DNS Records to Add

Publish a **ServiceMode HTTPS** (or **SVCB**) record under the `_index._agents` or `_a2a._agents` subdomain of your domain (`firststepco.com`).

### Format

```dns
_index._agents.firststepco.com. 3600 IN HTTPS 1 firststepco.com. alpn="h3,h2" port=443 mandatory=alpn,port
_a2a._agents.firststepco.com.   3600 IN HTTPS 1 firststepco.com. alpn="a2a" port=443 mandatory=alpn,port
```

* **Subdomain**: `_index._agents` or `_a2a._agents`
* **Type**: `HTTPS` (or `SVCB`)
* **Priority**: `1`
* **Target (Endpoint)**: `firststepco.com` (your main site URL)
* **Value / Parameters**:
  * `alpn="h3,h2"` (for standard Web/HTTP) or `alpn="a2a"` (for Agent-to-Agent communication)
  * `port=443`
  * `mandatory=alpn,port`

---

## 2. Configuration by Provider

### Cloudflare (Recommended)

1. Go to your Cloudflare Dashboard → **DNS** → **Records**.
2. Click **Add Record**.
3. Choose Type: **HTTPS**.
4. Configure:
   * **Name**: `_index._agents`
   * **Target**: `firststepco.com`
   * **Priority**: `1`
   * **Value**: `alpn="h3,h2" port=443`
5. Click **Save**.

### AWS Route 53

1. Go to Route 53 console → **Hosted Zones** → **firststepco.com**.
2. Click **Create Record**.
3. Configure:
   * **Record name**: `_index._agents`
   * **Record type**: `HTTPS`
   * **Value**: `1 firststepco.com. alpn="h3,h2" port=443`
4. Click **Create Records**.

---

## 3. Enable DNSSEC (Required)

AI agents and validating resolvers verify DNS-AID records via DNS-over-HTTPS (DoH). For these records to be trusted:

1. Enable **DNSSEC** in your DNS provider settings (e.g. Cloudflare DNSSEC toggle).
2. Copy the DS records generated by your provider.
3. Paste the DS records into your domain registrar's DNSSEC configuration page (e.g., GoDaddy, Namecheap, Hostinger).
4. Verify DNSSEC is active using a tool like [DNSViz](https://dnsviz.net) or by running:
   ```bash
   dig +dnssec _index._agents.firststepco.com HTTPS
   ```
